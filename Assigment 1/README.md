# 📊 Python for Data Science Assignment - Session 1

Welcome to **Session 1** of our Data Science journey! In this session, we cover the basics of Python programming as it applies to data science, including data structures, control flow, and basic operations.

## 📖 Overview of Session 1

In this assignment, you'll develop foundational Python skills needed for data analysis. The exercises include simple tasks that will help you get comfortable with Python syntax and logic.

## ✨ Exercises Included

1. **Basic Python Operations**  
   - Learn Python syntax and basic operations, including mathematical operations and string manipulations.

2. **Data Structures**  
   - Explore Python’s data structures such as lists, dictionaries, and sets, which are essential for handling data.

3. **Control Flow**  
   - Work with conditional statements and loops to automate repetitive tasks.
